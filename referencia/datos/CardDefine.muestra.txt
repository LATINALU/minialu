//
// 알파벳 ( *ALPHABET )은 기술되어 있지 않으면 랜덤하게 부여됨
// 모드 속성 ( *MODE ) 은 중복이나 없는것이 가능함
//

////////////////////////////////////
// 타입 ( *TYPE )값은 다음과 같음
// 0 : 일반 카드
// 1 : 네임드 카드
// 5 : 스페셜 카드 ( 전직 카드 )

////////////////////////////////////
// 캐릭터 ( *CHARACTER ) 값은 다음과 같음
// 0 : CHARACTER_CRO
// 1 : CHARACTER_MARSHALL
// 2 : CHARACTER_CARIBBEAN
// 3 : CHARACTER_KANGHYUK
// 4 : CHARACTER_PENNY
// 5 : CHARACTER_HIKARU
// 6 : CHARACTER_HOMAN
// 7 : CHARACTER_XIAH
// 13 : 전직 골리앗

////////////////////////////////////
// 플레이타입 ( *PLAY_TYPE ) 값은 다음과 같음
// 0 : PLAYTYPE_NONE			
// 1 : PLAYTYPE_SPECIAL		// 필살기 연속 사용형
// 2 : PLAYTYPE_BERSERK		// 파워 증폭형


////////////////////////////////////
// 모드속성 ( *MODE ) 값은 다음과 같음
// 0 : MODE_BATTLE		// 배틀
// 1 : MODE_SIEGE		// 공성
// 2 : MODE_DUNGEON		// 던전
// 3 : MODE_QUIZ		// 퀴즈
// 4 : MODE_TOURNAMENT		// 토너먼트
